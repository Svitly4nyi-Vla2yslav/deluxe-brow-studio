# Deluxe Brow Studio

Dark black-and-gold React/Vite design prototype using the six user-provided visual reference screens (hero, about/Instagram, three treatments, pricing/gift/booking).

## Run

```bash
npm install
npm run dev
npm run build
```

Netlify builds with `npm run build` and publishes `dist` via `netlify.toml`.

## Demo limits

Images are temporary remote stock placeholders, not approved studio photos. The before/after layout is a demonstration, not real client treatment outcomes. Prices and seasonal −30% discounts come only from the visual mockups and are not confirmed commercial offers. Booking calendar shows *requested* dates/times, no live availability. The booking form prepares a request and opens Instagram; it does not send/book automatically.
